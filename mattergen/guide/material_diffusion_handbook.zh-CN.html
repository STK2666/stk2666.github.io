材料发现要做两件不同的事。给定一个结构，可以估计它的能量或受扰动后的响应；给定一个设计要求，则要提出值得检验的结构。后一项任务有许多可能的解：同一种元素组合容许不同配比，同一个化学式也可以有不同的原子排列。本项目用一个生成模型给出这些候选，并追踪每个候选从随机状态到结构文件的过程。后续的模型预测、第一性原理计算与实验分别可以提供有关性质、稳定性和可实现性的证据。MatterGen 论文 · 项目交接说明（课程仓库，需权限）

第一幕　晶体表示与网络

1　计算机怎样表示一块周期性晶体？

从重复结构到三个变量

考虑向三个方向周期延拓的理想晶体。我们选取一个重复单元，记该晶胞内有 nn 个站点。晶格定义如何平移重复单元，基元定义每个重复单元中有哪些元素、位于哪里。一个三维点集仅给出一次摆放的坐标；加上周期晶格以后，才能确定跨晶胞的距离、邻居与整体对称性。当前模型面向小晶胞周期结构；材料的宏观形状、晶粒和缺陷需要各自的表征。官方权重模型卡

写 X=(A,F,L)X=(A,F,L)。AiA_i 为第 ii 个站点的一基原子序数。Fi∈[0,1)3F_i\in[0,1)^3 为无量纲的分数坐标。L∈ℝ3×3L\in\mathbb R^{3\times3} 的三行分别为三个晶格向量，以 Å 为单位。该站点连同全部周期像的笛卡尔位置为

ri,k=(Fi+k)L,k∈ℤ3. r_{i,k}=(F_i+k)L,\qquad k\in\mathbb Z^3 .

原胞内位置 R=FLR=FL，体积 V=|det⁡L|V=|\det L|，每原子体积为 V/nV/n。这三个公式分别决定前端怎样画点、怎样显示尺寸、怎样跨不同站点数比较几何尺度。例如坐标从 0.99 变到 0.01，有可能只沿第一条晶格方向跨过 0.02 个周期。观察跨界动画时应同时查看晶胞；在斜晶胞里，最短实空间距离还需用实际晶格搜索周期像。读写及坐标实现 · 每帧数据约定（课程仓库，需权限）

CIF 和张量怎样对应？

训练数据由 Materials Project 与 Alexandria 筛选得到，base 使用的缓存名为 Alex-MP-20，训练范围为至多 20 个站点的原胞。官方预处理从 CIF 读晶格、站点和元素，取原胞并进行 Niggli 约化，统一部分晶胞基底选择，再将分数坐标取模 1。base 的变换将行向量晶格替换为极分解中的对称因子 (LL𝖳)1/2(LL^\mathsf{T})^{1/2}，保持行向量的 Gram 矩阵，因而保留长度、夹角和体积。原胞化、约化可能改换基底及原子顺序。比较同一结构的两个文件时，要连同晶格和周期像一起核对。官方数据读取 · 原始数据处理与逐字段示例 · 训练数据说明

2　为什么选周期几何图网络，一次前向发生什么？

上述 Cu 和 Pd 在中央晶胞内的直线距离为 4.1330 Å。给 Pd 加晶格平移 (−1,0,−1)(-1,0,-1)，得到 2.6117 Å 的另一条位移。神经网络若仅比较中央三个点，会漏掉跨边界的局部环境。MatterGen 在当前坐标和晶格上动态构造 周期近邻图，图边对应满足近邻准则的一对周期像，化学成键需要额外判断。把一条边写为 (i,j,k)(i,j,k)，它的相对位移为 dij,k=(Fj+k−Fi)Ld_{ij,k}=(F_j+k-F_i)L。同一对站点编号可以因像偏移不同出现多次。实际站点数据（课程仓库，需权限） · 周期图实现

骨干是 GemNet-T 几何消息传递网络。 这里有四种决定预测的操作。

  1. 建图。 将当前分数坐标变为笛卡尔点，结合晶格搜索周期像。base 截断半径为 7 Å，最大近邻数配置为 50，每个晶格方向最多搜索 5 级周期像。图存 edge_index[2,E] 与整数像偏移 to_jimages[E,3]。当前几何更新后，下次前向会重新构图。
  2. 嵌入。 元素及 MASK 经查表得到 512 维节点向量。每个晶胞的 tt 经 256 对正弦、余弦编码成 512 维，向站点广播，与元素向量拼接后投影为节点隐藏态。空间位置通过相对边向量、距离和角度进入消息传递。径向基展开的默认数目为 128，角向基为 7；边方向与三条晶格轴的夹角还提供晶胞几何信息。
  3. 传递消息。 对共享中心的两条边构造三元组。边长描述“隔多远”，夹角描述“从哪两个方向靠近”。四个交互块更新 512 维边和节点特征，并汇集多层读出。即使两个局部环境的原子种类和若干边长相似，三元组仍可以帮助区分排列方式。
  4. 读出。 元素头从节点得 [N,101] 个干净类别 logits；位置头沿有向边以学到的标量加权单位方向，按站点聚合三维向量，换算到分数坐标分支；晶格头汇集与方向外积 uu𝖳uu^\mathsf T 相关的张量，得到对称 [B,3,3] 输出。后两项的统计含义是带噪状态的去噪信号。官方骨干还返回名为 energy 的量，但生成器从元素、位置、晶格三项读出构造候选。报告该材料的实际能量、力或应力需要专门的预测器或物理计算。固定模型配置 · GemNet-T 实现 · 去噪输出变换

哪些对称性有意义？ 调换站点的存储顺序应只调换站点级预测，对同一晶胞的整体预期保持一致。全体站点加上共同平移，边的相对位移保持不变。对空间作整体正交旋转，边长和夹角不变，沿边单位向量的笛卡尔向量读出随坐标轴旋转，方向外积按二阶张量变换。模型还在规范化的对称晶格表示中工作。近邻筛选的边界、等距排序和浮点归约顺序在数值层面均可能引入微小差异。以下探针给出置换与平移的单样本检查；旋转一项描述网络的几何构造。几何边与输出头 · 张量转换

第二幕　生成目标与模型选择

3　给材料模型一个“提示”，我们究竟规定了什么？

文生图中的一句提示可以指定“雪地里一辆红色汽车”，而视角、积雪形状与背景细节仍有多种可能。晶体设计同样留有自由度，条件可以有很明确的数学内容。写 cc 为要求，本项目在给定 nn 后希望从 pθ(A,F,L∣n,c)p_\theta(A,F,L\mid n,c) 采出候选；无性质条件时取 pθ(A,F,L∣n)p_\theta(A,F,L\mid n)。本轮实验从原有站点数分布取 nn，按实验设计保持配对。不同条件权重支持不同字段，条件的类型也决定应怎样独立检验输出。

4　这种任务应该选择什么扩散模型？

先把“生成什么”与“怎样分解生成”作为两个可组合的问题。图像和晶体都有空间结构，但常见图像潜变量的每个分量可以作连续插值；把 Cu 的类别编号与 Pd 的编号先平均，并不会给出一个有物理意义的“中间元素”。文本和元素都是类别，晶体中负责解释一个元素位点的上下文却还包含连续变化的邻居几何。这两点一起决定了 MatterGen 的联合生成形式。潜空间图像扩散 · 离散扩散 · MatterGen

结论怎样交给物理验证？

现在可以围绕同一个候选连续回答三类问题。它是怎么来的？ 看 checkpoint、条件、噪声与求解器、第一条记录、独立 final。它实现了哪些目标？ 从最终 CIF 重算元素集合、尺寸与对称性，并附具体阈值。它能否作为材料存在？ 需要与所声称的物理性质匹配的进一步检验，例如弛豫前后几何与残余力、相对于参考相的能量、对小位移的动力学响应。提交给物理组时保存输入 CIF 哈希，为弛豫后的输出另设 ID，用明确的对照将数据完整性、条件响应、物理判断串起来。这里的能量与声子仍是下游要回答的问题。交接字段（课程仓库，需权限） · 基础候选的物理验证记录状态

from pathlib import Path

import torch
from pymatgen.io.cif import CifParser
from mattergen.common.data.collate import collate
from mattergen.common.data.dataset import CrystalDataset, structures_to_numpy
from mattergen.common.data.transform import set_chemical_system_string, symmetrize_lattice
from mattergen.common.utils.data_classes import MatterGenCheckpointInfo
from mattergen.common.utils.eval_utils import load_model_diffusion

torch.set_num_threads(1)
cif = Path("deliverables/tk-cuda-seed48/final.cif")
weights = Path("external/models/checkpoints/mattergen_base").resolve()

with torch.inference_mode():
    structure = CifParser(cif).parse_structures(primitive=True)[0]
    structure.properties["material_id"] = "tk-cuda-seed48"
    arrays, properties = structures_to_numpy([structure])
    dataset = CrystalDataset(
        **arrays, properties=properties,
        transforms=[symmetrize_lattice, set_chemical_system_string],
    )
    graph = collate([dataset[0]])
    loaded = load_model_diffusion(MatterGenCheckpointInfo(model_path=weights)).cpu().eval()
    diffusion = loaded.diffusion_module
    torch.manual_seed(17)
    time = torch.tensor([0.4])
    noisy = diffusion.corruption.sample_marginal(graph, time)
    reference = diffusion.model(noisy, time)

    perm = torch.tensor([2, 0, 1])
    reordered = noisy.replace(pos=noisy.pos[perm], atomic_numbers=noisy.atomic_numbers[perm])
    translated = noisy.replace(pos=(noisy.pos + torch.tensor([0.25, 0.375, 0.625])) % 1)
    for name, variant, order in [
        ("permutation", reordered, perm),
        ("translation", translated, torch.arange(3)),
    ]:
        observed = diffusion.model(variant, time)
        for field in ("atomic_numbers", "pos", "cell"):
            expected = getattr(reference, field)
            if field != "cell":
                expected = expected[order]
            print(name, field, (getattr(observed, field) - expected).abs().max().item())
